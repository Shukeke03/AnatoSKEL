# AnatoSKEL v1.0

v0.1 is preserved at Git tag `v0.1` (baseline commit `2d732ae`). v1.0 is a new
architecture and checkpoint schema. Old weights are usable through the legacy
commands, but cannot initialize the new token shape space or diffusion model.
The repository version denotes implemented software, not a measured accuracy
improvement. No new real-data v1 training result is included in this release.

## Architecture

| Component | Research specification |
| --- | --- |
| Shared CT encoder | MONAI SwinUNETR V2; feature size 48, stages `(2,2,2,2)`, heads `(3,6,12,24)`, patch 2³, window 7³; pretrained Swin FFN GELU |
| Global context | S8/S16/S32 physically positioned features → 256 learned slots; 2 cross/self aggregators, width 384, 6 heads, SwiGLU hidden 1024 |
| Geometry queries | 64 instances × localization/identity/shape queries; 3 global + 3 local blocks; same-world-point query/content/position-dependent multiscale aggregation |
| CT detail | Wide HU + input validity; GroupNorm/SiLU residual branch and 5-resolution decoder; 32-channel final features |
| Shape AE | 4096 surface points + normals → 256 indexed tokens × 128; width 256, 8 heads, 4 latent blocks; point cross-attention and Softplus(20) SDF head |
| Initial latent | 2 fixed-slot CT cross/self blocks, width 384, heads 6, SwiGLU |
| Diffusion | 6 DiT blocks; self-attention → CT cross-attention → SwiGLU; AdaLN-Zero, cosine 1000-step v-prediction, Min-SNR; 20-step deterministic DDIM |
| Partial adapter | One zero-output `384→96→384` SiLU adapter per DiT block; enabled only during final 4 sampling steps |
| Continuous field | Shape SDF + CT-conditioned Softplus residual, distances in mm; one latent and one noise draw shared by all instance tiles |

The research model has129,321,945 parameters. This count does not estimate
activation memory or justify a particular GPU batch size.

Inference inputs are CT, affine and acquisition validity. Labels, GT centres,
registration rotations and GT shape tokens never enter the inference forward.
Identity is an output distribution; no hard vertebral class embedding selects
a shape template. The implementation borrows structured queries and geometry
reasoning from HSMR/VGGT, without importing their RGB weights or SKEL assets.

Every instance uses fixed `u=(x_RAS-anchor_RAS)/64mm`, without per-axis scaling.
All tiles remain at 1mm spacing. Default tile size is128³, overlap32 voxels;
centres are discrete coverage offsets around a predicted differentiable centre.
ROI expansion reads further CT, rather than increasing voxel spacing. Global
context stays directly available in the local query and diffusion memory.

## Coverage and supervision

Acquisition, annotation, conditioning and tile domains have separate roles.
Losses use acquisition∩annotation validity. Missing CT is explicitly marked;
unannotated regions do not become background. Artificial cropping happens
before the global encoder, proposals, local encoder and initial latent.

Complete surface targets are encoded only when the bone is conservatively
inside both scan and annotation domains. Real partial bones never produce a
full latent, residual or v target. Partial TSDF uses only bone/nonbone interfaces
between known voxels. Its distance target is accepted only if a conservative
physical distance to unknown support exceeds the clipped visible-surface
distance plus a margin. This avoids fake end caps and accounts for anisotropic
voxel-cell geometry. Occupancy remains supervised throughout the known domain.

Training objectives include detection class/mask/visible-centre/visible-box,
dense foreground and centre heatmap, fine occupancy/Dice/reliable TSDF,
observed surface/normal/Eikonal finite differences, tile consistency,
same-instance and same-world-point contrastive losses. Complete CT samples
also receive low-weight latent regression. Diffusion receives v-loss and
low-noise clean-latent geometry loss. Partial adapter training receives visible
final-sampling geometry and complete/synthetic-crop replay v-loss. Losses are
normalized by the valid supervised samples, with weights in `v1/pipeline.py`.
CT ROI warm-up uses visible GT plus jitter, followed by a gradual transition to
predicted centres and bounds. All evaluation and inference use predictions.

Freeze is parameter-only for the shape decoder: predicted latent, decoder
memory and SDF retain their autograd graph. During partial adaptation, the
shape AE, CT reference, CT detail head and base DiT are fixed. The first16
sampling steps have the adapter off; the final4 steps remain differentiable.
Only adapter weights update. The CT stage trains the other observation-domain
tasks using both complete and partial cases.

## Local and AutoDL environment

Python3.11, PyTorch2.8.0, MONAI1.5.1, einops0.8.1. Keep CUDA12.8 / cu128 on
AutoDL; do not substitute an older CUDA build for RTX5090. Existing
`requirements-cuda.txt` and `environment-gpu.yml` remain the GPU installation
sources. The package pins framework versions; macOS uses its existing CPU wheel.

```bash
conda activate anatoskel
python -m pip install -e '.[dev]'
ruff check .
pytest -q
python scripts/smoke_v1.py
```

The small smoke configuration reduces widths/tokens/steps for software checks.
It does not represent the research model or yield useful medical weights.
Checkpoint software provenance remains in exported JSON.

The default research encoder is randomly initialized unless
`model.pretrained_encoder` points to an official VoCo-B checkpoint. Its loader
requires at least95% matched parameters separately for Swin and residual skips,
rejects shape mismatches, and records exactly what was loaded. The new decoder,
bone branch and task heads remain newly initialized. An actual external VoCo
checkpoint has not been downloaded or benchmarked in this release.

Official weights/source: [VoCo](https://github.com/Luffy03/Large-Scale-Medical).
Place weights outside Git and set the local path in your run configuration.
Loading an existing v1 checkpoint does not require the old external weight path.

## Training stages

Use the existing deduplicated VerSe manifest. Do not reuse v0.1 atlas, latent
targets or ROI caches as v1 training targets. Each stage saves `model.pt`,
optimizer, RNG, patient provenance, stage cursor and readiness markers.

```bash
anatoskel train-v1 --stage shape --config configs/v1_autodl_4090.yaml \
  --manifest data/verse/processed/manifest.jsonl --output outputs/v1/shape --device cuda

anatoskel train-v1 --stage ct --config configs/v1_autodl_4090.yaml \
  --manifest data/verse/processed/manifest.jsonl --init outputs/v1/shape/model.pt \
  --output outputs/v1/ct --device cuda

anatoskel train-v1 --stage diffusion --config configs/v1_autodl_4090.yaml \
  --manifest data/verse/processed/manifest.jsonl --init outputs/v1/ct/model.pt \
  --output outputs/v1/diffusion --device cuda

anatoskel train-v1 --stage partial --config configs/v1_autodl_4090.yaml \
  --manifest data/verse/processed/manifest.jsonl --init outputs/v1/diffusion/model.pt \
  --output outputs/v1/partial --device cuda
```

`--init` starts the next stage; `--resume outputs/v1/ct/model.pt` resumes that
same stage. `--max-steps` is a positive total step limit for the current stage.
Change `train.epochs` per stage/run before launching long jobs. Diffusion first
calibrates and freezes residual channel statistics from complete training shapes
and the fixed CT predictor, including deterministic synthetic-crop conditions
with full GT re-encoded in each predicted frame. The calibration recipe and
statistics travel with the checkpoint. Changing the shape AE or CT reference
invalidates downstream readiness/statistics; changing the base diffusion resets
its old partial adapters.

Research defaults are BF16, activation checkpointing, one scan and at most two
bone instances per CT step. Additional tiles increase activation cost. Local
tests cover CPU/BF16 math and gradients; actual CUDA peak memory and throughput
must be profiled on4090/5090 before choosing a larger bone batch. This release
does not estimate clinical-training runtime from CPU smoke timing.

## Evaluation and OBJ

The existing `infer`/`evaluate` commands automatically dispatch by checkpoint
schema. Evaluation uses predicted identities and predicted coverage; missed GT
bones score zero, and Dice is limited to annotation-valid native CT voxels.

```bash
anatoskel evaluate --checkpoint outputs/v1/partial/model.pt \
  --manifest data/verse/processed/manifest.jsonl --split val \
  --output outputs/v1/val.json --device cuda

anatoskel infer --checkpoint outputs/v1/partial/model.pt \
  --manifest data/verse/processed/manifest.jsonl --split test \
  --output outputs/v1/prediction --device cuda
```

`bones_observed.obj` is restricted to acquisition support, with exact clipping
against the original physical FOV, including oblique/reflected affines. Unknown
SDF values are never converted into background caps. Scanning truncation stays
open; artificial tile gaps trigger expansion/error. `bones.json` records RAS
millimetres, anchors, tile counts, diffusion steps, coverage, training status and
open boundaries. All in-scan surfaces remain model estimates. Unobserved full
completion is deliberately not exported by the default command.

## Research boundary

Latent medical diffusion and observed-domain completion already exist, e.g.
[GenMed](https://arxiv.org/html/2605.10645v1). The proposed combination here is
complete-shape prior learning, real-partial final-sampling adaptation and shared
instance geometry across computational tiles. Its accuracy and incremental
research value require real training results. Correct gradient/domain handling
and open export are software requirements, not standalone novelty claims.
